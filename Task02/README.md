# Task02

## Лабораторная работа 2

### Требования к окружению
- Python версии 3.x
- SQLite (командная строка `sqlite3` должна быть доступна в PATH)
- Git

### Как запустить
1. Убедись, что Python и SQLite установлены.
2. на Windows просто дважды кликни по `db_init.bat`.
3. После успешного выполнения в папке появится база данных `movies_rating.db` с заполненными таблицами `movies`, `ratings`, `tags`, `users`.

### Файлы
- `make_db_init.py` — утилита генерации SQL-скрипта
- `db_init.sql` — сгенерированный SQL-скрипт (создаётся автоматически)
- `db_init.bat` — скрипт для запуска утилиты и загрузки данных в БД
- `movies_rating.db` — база данных SQLite (создаётся автоматически)
- `*.csv`, `users.txt` — исходные данные
