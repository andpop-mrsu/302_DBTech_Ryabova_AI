# Task01

Лабораторная работа 1. Подготовка окружения для выполнения заданий и интерактивной работы с СУБД SQLite.

## Структура файлов данных

- `ratings.csv` — оценки пользователей фильмам (userId, movieId, rating, timestamp)
- `movies.csv` — информация о фильмах (movieId, title, genres)
- `tags.csv` — теги, проставленные пользователями фильмам
- `users.txt` — информация о пользователях
- `genres.txt` — список жанров
- `occupation.txt` — список профессий пользователей

## Результаты

- `ratings_count.txt` — минимальный и максимальный идентификатор пользователя из `ratings.csv` и количество строк с ними
- `sqlite.txt` — версия SQLite и режимы вывода данных, доступные в утилите `sqlite3`

## Инструменты

- СУБД: SQLite 3.53.4
- Система контроля версий: Git
- Хостинг репозитория: GitHub
